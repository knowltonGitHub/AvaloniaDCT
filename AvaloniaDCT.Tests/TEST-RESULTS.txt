WHAT WAS RUN
------------------------------------------------------------------------------

These tests call app services (ClipboardStore, SqliteDatabase, SQLCipher
key derivation helpers, backups, LAN chat, Preferences load/save). They
do not open Avalonia windows or click the UI.

Local SqliteDatabase still uses the typed password as the SQLCipher key
(no PBKDF2 rekey). Incoming tests that expected TryCreateCopy / .kdf
migration were rewritten to match that local API.


PASSED TESTS
------------------------------------------------------------------------------

ClipboardStoreTests  (main screen: tags / items / values in memory)

  PASS  AddTag_then_AddItem_reuses_the_placeholder_and_lists_the_value
        First item fills the empty tag row; left/middle/right lists agree.

  PASS  RenameTag_and_DeleteTag_change_the_left_list
        Rename updates every row; delete removes the tag and its items.

  PASS  DeleteItem_keeps_an_empty_tag_row
        Last item gone, tag still appears so the left list does not jump.

  PASS  TagExists_and_ItemExists_match_what_Add_refuses
        Duplicates are detected; rename item and edit value work.

  PASS  IsWebUrl_and_ToBrowsableUrl_match_the_open_url_button
        Empty/plain text vs hosts; https:// is added when missing.

  PASS  Load_replaces_previous_rows
        Login-style Load wipes prior memory and keeps SQLite rows.


SqliteDatabaseTests  (login, clipboard persist, encryption, Preferences)

  PASS  Unencrypted_database_supports_login_and_tag_item_crud
        Debug file: knowlton seed, wrong password rejected, overwrite
        replace-all, no .kdf sidecar, file opens without a SQLCipher key.

  PASS  Hardened_database_keeps_rows_and_rejects_the_wrong_password
        Create account, clipboard row survives reopen, wrong password
        fails, typed password is still the SQLCipher key.

  PASS  SavePreferences_then_LoadPreferences_returns_the_smtp_fields
        File > Preferences SMTP DTO round-trips through SQLite.

  PASS  Existing_preference_rows_survive_initialize
        Leftover SMTP/LAN preference columns are not dropped on Initialize.

  PASS  Wrong_password_does_not_open_a_hardened_database
        Bad password does not write .kdf or open the file.

  PASS  DeriveKey_changes_when_the_salt_changes
        Different salt → different key.
